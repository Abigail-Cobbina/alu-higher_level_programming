# Python - Almost a Circle

This project is about creating and testing Python classes related to geometric shapes.

## Description

The project focuses on object-oriented programming, class inheritance, unit testing, and serialization in Python.

## Files

- models/base.py - Base class for the project
- models/rectangle.py - Rectangle class
- models/square.py - Square class
- tests/ - Unit tests for all classes and methods

## Testing

Run the tests with:

python3 -m unittest discover tests
