This test file documents the MyList class.

MyList inherits from the built-in list class.

Methods:
- print_sorted(self): Prints the list in ascending order without modifying the original list.

Example:

>>> MyList = __import__('1-my_list').MyList
>>> my_list = MyList([3, 1, 2])
>>> my_list.print_sorted()
[1, 2, 3]
>>> print(my_list)
[3, 1, 2]
